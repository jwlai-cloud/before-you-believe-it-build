# Before You Believe It — three-minute capture plan

**Status:** Ready for static capture. The live segment needs the judge access code to be entered by an authorized person in the deployed app.

## Story promise

Before You Believe It gives parents and children a small, repeatable weekend activity for an AI-shaped world. It does not ask a child to accept, defeat, or be graded by AI. It helps a family slow down, ask what a confident AI claim assumes, look for a different view, and make a child-owned working answer together.

## Capture method

1. Capture each shot as a separate clip at 1920×1080, with a clean browser profile and no extension UI, bookmarks, notifications, access code, or personal information visible.
2. Record static interaction clips first. Keep two seconds of handle before and after each action for editing.
3. For the live clip, record the unlock action only after the code is masked or entered off-screen. Stop the recording as soon as the request is submitted.
4. Insert the pause card while the real request completes. Resume a fresh recording when the validated material has rendered; no generated text is scripted or fabricated.
5. Record narration only after the edited visual timeline is locked. Use captions throughout so the film works muted.

## Capture safety

- Do not record or publish the judge access code, an API key, cookies, or a private child response.
- Use a non-personal topic such as `school gardens` for the live request.
- If the live call fails, retain the honest fallback sequence: the preset activity remains the full demo; do not replace the live output with invented model content.
